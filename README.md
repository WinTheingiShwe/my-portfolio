# Personal Portfolio Website

HTML、CSS、JavaScriptを使用して制作した、就職活動向けのポートフォリオWebサイトです。

データ分析やWeb開発に関する学習内容、制作実績、技術スキルを紹介しています。

## プロジェクト概要

このWebサイトは、自分が学んできた技術や制作したプロジェクトを分かりやすく紹介することを目的として制作しました。

シンプルで見やすいUIデザインを意識し、パソコンとスマートフォンの両方で閲覧できるレスポンシブデザインを採用しています。

## 使用技術

- HTML5
- CSS3
- JavaScript
- Git / GitHub
- GitHub Pages（公開予定）

## 主な機能

- **About Me**：自己紹介
- **Technical Skills**：学習した技術の紹介
- **Projects**：制作実績の紹介
- **Learning & Practice**：SQL・Pythonの学習内容
- **Education & Certifications**：学歴・資格
- **Contact**：GitHubへのリンク

## フォルダ構成

```text
my-portfolio/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Webサイトの開き方

1. このリポジトリをダウンロードします。
2. `my-portfolio` フォルダを開きます。
3. `index.html` をブラウザで開きます。

Visual Studio CodeのLive Serverでも確認できます。

## 制作実績

運動・食事データを記録し、月ごとの変化を集計・可視化することを目的としています。

現在開発中です。

GitHub：
https://github.com/WinTheingiShwe/school_project_FitTrack

## GitHub Pages

GitHub Pagesを使用して公開する予定です。

公開手順：

1. GitHubにリポジトリを作成
2. ファイルをアップロード
3. Settings → Pagesを開く
4. Deploy from a branchを選択
5. `main` ブランチと `/(root)` を指定
6. Saveをクリック

## 個人情報について

公開用ポートフォリオでは、個人情報の取り扱いに注意しています。

氏名、顔写真、メールアドレス、学校情報などは、公開前に掲載内容を確認し、必要に応じて削除・匿名化します。
